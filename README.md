# React Product Card

A responsive product card for the GoMyCode React Components and JSX checkpoint. Built with React and React Bootstrap.

## Features

- Product name, price, description and image displayed through reusable components.
- Shared product data in `src/product.js`.
- A personal greeting and welcome image when a name is provided.
- A layout that adapts to smaller screens.

## Run locally

Open the project folder in VS Code, then open **Terminal → New Terminal** and run:

```bash
npm install
npm start
```

Open the local address shown in the terminal.

## Make it your own

Edit `src/product.js` to change the product. Change `firstName` in `src/App.js` to personalise the greeting, or leave it empty to display “Hello, there!”.
